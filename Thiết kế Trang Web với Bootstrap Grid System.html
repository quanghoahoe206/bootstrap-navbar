Bootstrap Grid System

Bootstrap Grid System giúp chúng ta xây dựng bố cục website một cách nhanh chóng và responsive trên nhiều kích thước màn hình.

Grid của Bootstrap được chia thành 12 cột. Chúng ta có thể kết hợp các class như col-md-8 và col-md-4 để tạo bố cục hai cột.

Responsive Layout

Trên màn hình desktop, phần nội dung chính chiếm 8 cột và Sidebar chiếm 4 cột. Khi chuyển sang màn hình nhỏ, cả hai phần sẽ chuyển thành một cột và Sidebar nằm bên dưới nội dung chính.
